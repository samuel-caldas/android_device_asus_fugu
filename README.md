# android_device_asus_fugu

Device tree para compilação do sistema operacional Android (LineageOS / AOSP) no Google Nexus Player (codinome Asus Fugu, plataforma Intel x86 Silvermont).

## 🛠️ Tecnologias

- **Android Build System**
- **Makefile**
- **C/C++**
- **Linux Kernel**

## 📂 Estrutura do Projeto

- `BoardConfig.mk`: Configurações de hardware, arquitetura x86 e partições.
- `device.mk` & `AndroidProducts.mk`: Definição de pacotes e produtos do dispositivo.
